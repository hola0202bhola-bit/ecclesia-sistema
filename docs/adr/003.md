# ADR 003 — Persistencia PostgreSQL con Prisma

Actualización revisión 03, 1 de noviembre de 2026, America/Mexico_City. La versión 02 íntegra permanece en antecedentes.

## Estado y procedencia

Prisma y PostgreSQL confirmados por alumno; esquema mínimo aplicado con supuestos PC-02 explícitos.

## Justificación y alternativas

FK y CHECK llevan integridad a BD; UPDATE condicional versionado evita dos ganadores concurrentes. Prisma simplifica acceso tipado; SQL explícito conserva restricciones no expresables en schema. SQL manual es alternativa válida con mayor carga de mapeo.

## Consecuencias y verificación

Migración/seed y pruebas sobre PostgreSQL real, no SQLite/memoria. Tipo y geografía con referencias; perfil provisional no es modelo final. No imponer nulabilidad global hasta G1. PostgreSQL embebido es dependencia de desarrollo con wrapper beta; no es arquitectura de despliegue.

La revisión humana de esta implementación sigue pendiente; no se declara validación del cliente ni cierre de Fase 0.
